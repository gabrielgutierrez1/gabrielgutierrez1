## 🚀 Proyectos destacados

### 📚 [ApuntesUCT](https://github.com/cchelooo/ApuntesUCT)

---

### 📐 [EID — Introducción al Cálculo](https://github.com/gabrielgutierrez1/EID_Introduccion-al-calculo)

Aplicación desarrollada en Python para trabajar con **ecuaciones y secciones cónicas**.

Incluye:

- Validación de RUT
- Clasificación automática de cónicas
- Transformación entre forma general y canónica
- Cálculo de elementos matemáticos
- Interfaz gráfica con Tkinter
- Visualización del procedimiento paso a paso

**Tecnologías:**  
`Python` · `Tkinter`

---

### 📊 [EID — Álgebra / PCA](https://github.com/gabrielgutierrez1/EID_Algebra)

Proyecto que implementa **Principal Component Analysis (PCA)** utilizando conceptos de Álgebra Lineal.

Trabaja con matrices de covarianza, autovalores, autovectores y proyecciones para reducir la dimensionalidad del dataset Iris.

**Tecnologías:**  
`Python` · `NumPy` · `Matplotlib` · `Scikit-Learn` · `Tkinter`
